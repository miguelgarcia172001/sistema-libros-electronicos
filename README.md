## Descripción del proyecto

Este proyecto consiste en el desarrollo de un Sistema de Gestión de Libros Electrónicos desarrollado en Java, diseñado para administrar recursos digitales dentro de una biblioteca virtual.

La aplicación permite gestionar usuarios registrados, almacenar libros electrónicos, controlar préstamos, gestionar devoluciones y administrar diferentes procesos internos del sistema utilizando Programación Orientada a Objetos.

Durante el desarrollo del proyecto se integraron todos los conocimientos adquiridos durante las cuatro unidades de la asignatura.

---

## Objetivo del programa

Desarrollar una aplicación capaz de gestionar de forma organizada una biblioteca digital, permitiendo administrar usuarios, libros electrónicos, préstamos y devoluciones, aplicando conceptos fundamentales de Programación Orientada a Objetos e incorporando tecnologías complementarias utilizadas en el desarrollo moderno de software.

---

## Funcionalidades principales

El sistema desarrollado permite ejecutar las siguientes funciones:

- Registro de usuarios  
- Registro de libros electrónicos  
- Visualización de usuarios registrados  
- Visualización de libros almacenados  
- Búsqueda de libros específicos  
- Gestión de préstamos  
- Devolución de libros  
- Eliminación de libros  
- Generación de reportes administrativos

## Servicios web implementados

Dentro del proyecto se simularon ocho servicios web basados en arquitectura tipo REST.

- POST /usuarios  
- GET /usuarios  
- POST /libros  
- GET /libros  
- GET /libros/busqueda  
- POST /prestamos  
- PUT /prestamos/devolver  
- DELETE /libros

## Implementaciones avanzadas

Como parte de la fase final del proyecto se incorporaron nuevas funcionalidades adicionales.

### Serialización JSON

Permite convertir objetos del sistema a un formato estructurado utilizado comúnmente en aplicaciones web modernas.

### Concurrencia

Se implementó concurrencia mediante Threads en Java para simular múltiples usuarios accediendo simultáneamente al sistema.
