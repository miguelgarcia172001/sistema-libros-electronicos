# Sistema de Gestión de Libros Electrónicos

## Descripción del proyecto
Este proyecto consiste en el desarrollo de un Sistema de Gestión de Libros Electrónicos, el cual permitirá administrar libros digitales, usuarios y préstamos dentro de una plataforma organizada.

El sistema será diseñado aplicando principios de Programación Orientada a Objetos (POO), permitiendo una estructura modular, reutilizable y escalable.

## Objetivo
Desarrollar un sistema de gestión de libros electrónicos que permita organizar, controlar y administrar recursos digitales académicos mediante una estructura basada en clases y objetos.

## Módulos del sistema
- Gestión de usuarios
- Gestión de libros electrónicos
- Gestión de préstamos
- Administración general del sistema

## Tecnologías utilizadas
- Java
- GitHub
- UML
- Programación Orientada a Objetos (POO)
- Programación Funcional

## Diagrama UML
El proyecto incluye un diagrama UML que representa la estructura general del sistema, las clases principales y las relaciones entre los diferentes módulos.
